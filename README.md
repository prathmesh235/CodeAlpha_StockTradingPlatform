# CodeAlpha Stock Trading Platform

## Task 2 - Java Programming Internship

A console-based stock trading simulation developed using Java and Object-Oriented Programming.

## Features

- View stock market data
- Buy stocks
- Sell stocks
- Track portfolio
- View transaction history
- View account balance
- Simulate market price changes
- Save portfolio data to a file
- Object-Oriented Programming
- File I/O

## Technologies Used

- Java
- OOP
- Collections
- File Handling
- Exception Handling
- Date and Time API
